# Salami Prompt

`salami_batch_prompt.txt` is a prompt template for generating Salami-style
segmented translations through the OpenAI Batch API.

The template uses the following placeholders:

```text
{text}
{target_language}
```

If this prompt is adapted from a prior paper, cite the original paper in the
main README or in the project page. If you use the exact wording from the paper,
make that attribution explicit. A safer public-release option is to use this
rephrased version and cite the method/source.
