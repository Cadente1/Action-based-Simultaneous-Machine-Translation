Action-based Simultaneous Machine Translation

A research toolkit for action-based simultaneous machine translation, supervised seq2seq fine-tuning, few-shot LLM translation, and latency-aware text-to-speech synthesis.

Overview

This project explores simultaneous machine translation from an action-based perspective. The repository includes scripts for preparing text-to-text data, fine-tuning mBART-style sequence-to-sequence models, running prompt-based LLM translation, and synthesizing latency-aware speech outputs.

Repository

The codebase contains three main parts:

  • Supervised fine-tuning: data preparation, mBART-style training, and seq2seq inference.
  • Few-shot LLM translation: prompt-based translation with causal language models.
  • Latency-aware TTS: alignment, WAIT insertion, time-table construction, and TTS synthesis.
Code arXiv

Pipeline

Translation modeling: prepare_t2t_csv.py → train_seq2seq.py → infer_seq2seq.py
Few-shot translation: infer_llm_translation.py
Latency-aware TTS: alignment.py → wait_insertion.py → time_table.py → tts.py
