Overview

This project explores how simultaneous machine interpretation can learn from human interpreter strategies and better balance translation quality and latency. We extend the action space from READ and WRITE with four new actions: Drop, Sentence_Cut, Partial_Summarization, and Pronominalization.

Conventional action space

Most simultaneous MT systems formulate the policy with two basic actions: read more source context or write target output.

READ WRITE

Interpreter-inspired action space

We add flexible actions that allow the model to drop, split, summarize, or pronominalize content under latency pressure.

DROP SENTENCE_CUT PARTIAL_SUMMARIZATION PRONOMINALIZATION

Proposed New Actions

The proposed actions capture behaviors commonly used by human interpreters under latency pressure.

READ

Read the next source token or segment when more context is needed.

WRITE

Generate a target-language fragment from the observed source context.

DROP

Remove fillers, repetitions, self-corrections, or semantically weak material.

SENTENCE_CUT

Split long or complex sentences into shorter translatable units.

PARTIAL_SUMMARIZATION

Compress redundant expressions while preserving core meaning and tone.

PRONOMINALIZATION

Replace repeated noun phrases with pronouns when referents are unambiguous.

Method Overview

We design two evaluation tracks: encoder-decoder fine-tuning and decoder-only LLM adaptation, showing that the proposed four actions improve translation quality and reduce delay.

Open method overview PDF

Track A

mBART50 fine-tuning

Training source sentences come from the MuST-C English training set. We use three supervision signals for each target language, including offline gold translations, salami-segmented translations, and action-based translations.

Evaluation: MuST-C tst-HE and ACL60/60 evaluation set.

Track B

Decoder-only LLM adaptation

We compare two axes: the adaptation paradigm that guides the LLM and the behavioral signal that specifies what simultaneous interpretation behavior is provided or learned by the model.

Step-wise Inference

During online inference, the model observes the current source prefix, selects the next action, and outputs an incremental translation when applicable.

Offline preparation

Generate action-specific translations on the development set, estimate per-action quality-latency statistics such as BLEU and LAAL, and construct an action-aware prompt.

Online step-wise inference

Given the current source prefix and previous target output, the LLM selects the next action and produces an incremental translation if needed.

Prompt Example

A simplified and sanitized example of the action-aware prompt used for decoder-only LLM adaptation. 

You are a simultaneous interpretation agent.
Your task is to translate an English sentence into {target_language}
using incremental, step-by-step processing.

At each step, choose one of the following actions:

1. READ — Read the next English word.
2. WRITE — Output a target-language translation fragment based on the words read so far.
3. DROP — Remove previous word(s) when they are fillers, repetitions, thinking words,
   or self-corrections.
4. CUT — Split a long or complex sentence into shorter units.
5. SUMMARIZE — Compress redundant or repetitive expressions while preserving meaning.
6. PRONOUN — Replace repeated noun phrases with pronouns only when referents are clear.

Use action statistics such as BLEU and LAAL to balance quality and latency.

Please answer in JSON format.

{source_prefix}

{previous_output}

Results

We evaluate the proposed action-based framework under two settings: supervised encoder-decoder adaptation with mBART50 and decoder-only LLM inference with Qwen3-8B. Overall, action-aware supervision and action-guided inference improve the quality-latency trade-off across English-Chinese, English-German, and English-Japanese evaluation settings.

Track A

mBART50 supervised adaptation

Action-based training targets produce stronger supervised SiMT models than original offline references or salami-style references. On ACL60/60 eval, action-based mBART50 reaches 45.07 BLEU / 2.533s LAAL for En-Zh and 36.02 BLEU / 1.189s LAAL for En-De.

Track B

Decoder-only LLM inference

Action-guided inference provides finer control than salami prompting, TransLLaMA-style tuning, or static few-shot prompting. The Drop + Sentence_Cut setting gives the strongest overall quality-latency balance on ACL60/60 eval.
